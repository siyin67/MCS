# Minecraft Survivor

2D 俯视角 Minecraft 主题生存游戏，击败怪物获取经验升级武器。

## 运行

双击 `game.exe` 即可启动，无需安装任何依赖。

## 操作

| 操作 | 按键 |
|------|------|
| 移动 | WASD |
| 攻击方向 | 鼠标 |
| 暂停 | Esc |

## 玩法

- 击杀怪物获得经验值，满经验自动升级并获得一把随机武器
- 不同武器有各自的攻击方式和冷却时间
- 武器可升级，随等级提升伤害、范围等属性
- 存活尽可能久，击败更多怪物
- 在主页输入 Minecraft 正版 ID 并点击确认，可获取你的皮肤作为角色外观

## 武器

| 武器 | 说明 |
|------|------|
| Iron Sword | 近战扇形攻击 |
| Bow | 远程射箭 |
| Shield | 旋转护盾 |
| TNT | 投掷爆炸 |
| Trident | 追踪三叉戟 |
| Clock | 重置全部冷却 |
| Axe | 回旋飞斧 |
| Dragon Breath | 毒雾区域 |
| Sea Heart | 弹射水滴 |
| Lava Bucket | 熔岩地面 |
| Mace | 圆形重击 |
| Lightning Rod | 连锁闪电 |

## 文件说明

- `game.exe` — 游戏主程序
- `*.dll` — 运行所需库文件
- `assets/` — 游戏资源（贴图、音效、配置）
- 游戏进度不会写入文件，关闭即重置
