## 二、项目概述

Minecraft Survivor 是一款2D俯视角的类吸血鬼幸存者（Vampire Survivors）玩法的Minecraft主题游戏。玩家操控角色在地图上移动，自动攻击周围的怪物，击杀怪物获得经验值，升级后可获取随机武器。游戏目标是存活尽可能久、击败更多怪物。

### 核心玩法
- **WASD移动** + 鼠标控制攻击方向
- 武器自动攻击范围内的怪物
- 击杀怪物获得经验球（XP Orb）
- 经验满后自动升级，从3把随机武器中选择1把
- 12种武器各有独特的攻击方式和冷却时间
- 武器可随等级提升伤害、范围等属性
- 支持输入Minecraft正版ID获取玩家皮肤

### 3.2 核心设计模式

| 设计模式 | 应用位置 | 说明 |
|----------|----------|------|
| **状态模式** | `StateManager` + `IState` | 状态栈管理游戏场景切换（菜单→游戏→暂停→升级→结束） |
| **工厂模式** | `WeaponFactory` | 根据名称字符串创建武器实例 |
| **单例模式** | `ResourceManager`、`SoundManager` | 全局唯一的资源与音效管理 |
| **策略模式** | `Weapon::attack()` | 每种武器实现不同的攻击策略 |
| **观察者模式** | Callback机制 | 武器通过回调将投射物注入ProjectileManager |
| **模板方法** | `Monster::update()` | 基类定义更新流程，子类重写特定行为 |

## 四、关键技术实现

### 4.1 碰撞检测系统

采用**两级检测策略**，兼顾性能与精度：

1. **AABB 快速排除**（第一级）：利用 `sf::FloatRect::findIntersection()` 快速判断包围盒是否相交。适用于所有碰撞对。

2. **SAT（分离轴定理）精确检测**（第二级）：仅对**涉及Bullet的碰撞对**启用。将两物体顶点投影到法线轴上，检测分离间隙。正确处理旋转矩形和凸多边形的精确碰撞。

```cpp
// 碰撞决策策略
bool checkCollision(ICollidable *objA, ICollidable *objB) {
    if (!aabbCollide(boundsA, boundsB)) return false;  // 快速排除
    if (involvesBullet(objA->getType(), objB->getType()))
        return satCollide(objA->getVertices(), objB->getVertices());  // 精确检测
    return true;  // AABB 即认为碰撞
}
```

所有可碰撞实体（Player、Monster、Bullet）继承 `ICollidable` 接口，实现 `getGlobalBounds()` 和 `getVertices()`。

### 4.2 波次生成系统

`Spawner` 管理4级怪物梯度（Common → Uncommon → Rare → Boss），随波次提升逐步解锁高级怪物：

- 每波持续一定时间，波次结束后间隔短暂休息
- 怪物生成数量受 `maxAlive` 限制，防止无限堆积
- 生成位置在玩家视野外随机选择
- Boss级怪物在后期波次中低概率出现

### 4.3 程序化地图生成

使用 **Perlin Noise** + **分形噪声（Fractal Noise）** 生成 5000×5000 像素的Minecraft风格地形：

- **高度图**（4 octaves主地形 + 2 octaves细节扰动）决定地形类型
- **湿度图**（3 octaves独立种子）细分草地/沙滩
- 7种地形：草地、泥土、石头、圆石、沙地、水、岩浆
- 地图边界自动为水域
- 使用 `sf::RenderTexture` 预渲染整张地图到纹理

### 4.4 Buff/Debuff系统

`BuffManager` 管理玩家和怪物身上的状态效果：

| Buff类型 | 效果 | 触发方式 |
|----------|------|----------|
| SpeedUp/SpeedDown | 移速倍率 | 药水/怪物技能 |
| AttackUp/AttackDown | 伤害倍率 | 药水/怪物技能 |
| Invincible | 无敌 | 药水 |
| Heal | 每秒回复HP | 药水/区域效果 |
| Burn | 每秒伤害 | 熔岩地板/烈焰人 |
| Poison | 每秒伤害 | 女巫药水 |
| Wither | 每秒伤害 | 凋零/Boss区域 |

Tick类Buff（Heal/Burn/Poison/Wither）每秒触发一次伤害/治疗。

### 4.5 武器系统

**12种武器**各有独特的攻击模式：

| 武器 | 攻击方式 | 特殊机制 |
|------|----------|----------|
| Iron Sword | 近战扇形范围 | 基础武器 |
| Bow | 直线箭矢 | 远程 |
| Shield | 360°旋转碰撞 | 被动防御 |
| TNT | 投掷爆炸范围 | AOE |
| Trident | 追踪最近怪物 | 自动索敌 |
| Clock | 无直接伤害 | 重置所有武器冷却 |
| Axe | 回旋飞斧 | 往返伤害 |
| Dragon Breath | 放置毒雾区域 | 持续AOE+Buff |
| Sea Heart | 弹射水滴 | 链式攻击 |
| Lava Bucket | 放置熔岩地板 | 持续灼烧 |
| Mace | 圆形重击 | 近距离AOE |
| Lightning Rod | 连锁闪电 | 多目标跳跃 |

武器通过 `WeaponFactory::create(name)` 创建，支持JSON配置的升级曲线。

### 4.6 玩家系统

- **移动**：WASD + 归一化对角线，有效速度受Buff影响
- **无敌帧**：受伤后0.2秒无敌，红白闪烁视觉反馈
- **击退**：指数衰减的击退速度
- **经验/升级**：`XP → level_ * 100` 升级阈值，升级时弹出武器选择

### 4.7 网络功能 — Minecraft皮肤获取

`MenuState` 中通过 Mojang API（`https://api.mojang.com/users/profiles/minecraft/<username>`）异步获取玩家UUID，再获取皮肤纹理，将皮肤应用到玩家角色上。

## 七、总体评价

### 技术亮点
- 架构清晰，采用状态模式管理游戏场景，模块化程度高
- 碰撞检测采用AABB+SAT两级策略，兼顾性能与精度
- 武器系统设计灵活，每种武器独立实现攻击逻辑
- Buff系统支持多种状态效果叠加
- 程序化地图生成使每次游戏体验不同
- 代码规范，注释合理（中文注释），命名清晰

### 可改进方向
- 怪物AI可进一步增强（如寻路、躲避）
- 可增加数据持久化（存档/读档功能）
- 可增加更多波次事件和Boss机制
- 可优化大量怪物时的渲染性能
